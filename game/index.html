01 / CONTROLS

Read the cut.

Press A for blue or L for red when a block meets the strike line. Use the arrow as a directional cue; the demo accepts a hit on the matching side.

02 / SCORING

Keep your flow.

Well-timed cuts build combo and score. Early, late, and missed blocks break your streak. You can pause, mute, or start a fresh run any time.
